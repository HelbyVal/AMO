## Текст практического задания

### Требования к выполнению

1. Переконфигурируйте проект для использования Poetry вместо ручного управления
зависимостями (pip). Для этого:
* создайте файл pyproject.toml с описанием зависимостей проекта (catboost,
scikit-learn, pandas, pickle…);
* настройте Poetry для установки зависимостей и создания виртуального
окружения.
2. Измените скрипты сборки в Jenkins, чтобы они включали следующие шаги:
* инициализация Poetry-окружения;
* установка зависимостей через Poetry;
* последовательный запуск Python-скриптов (create_dataset.py, train_model.py,
prediction.py) для выполнения этапов ML-пайплайна;
* вывод статусных сообщений о начале и завершении каждого этапа
(аналогично примеру из lab-04).
3. Убедитесь, что все артефакты сохраняются корректно:
* тренировочный и тестовый датасеты в формате CSV;
* обученная модель в формате pickle;
* результаты предсказаний.
4. Проверьте корректность работы пайплайна в Jenkins:
* запустите сборку и проследите за статусом выполнения каждого этапа;
* проанализируйте вывод в консоли на предмет ошибок;
* убедитесь, что финальное предсказание для первого пассажира из тестового
набора выводится корректно.

### Необходимые шаги

1. Установите Poetry на сервер, где будет выполняться сборка.
2. Создайте файл pyproject.toml в корне проекта с перечнем необходимых зависимостей.
3. В Jenkins настройте выполнение shell-команд, включающих:
```
poetry install
python3
/home/ubuntu/project/create_dataset.py
echo "----Create Dataset (end)----"
python3 /home/ubuntu/project/train_model.py
echo "----Train the Model (end)----"
python3 /home/ubuntu/project/prediction.py
echo "----Use the Model for Prediction (end)----"
```
4. Скорректируйте пути к файлам в соответствии с вашей структурой проекта.
